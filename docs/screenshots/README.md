# OpenHandScan Studio screenshots

All four are from the app's simulator demo (a simulated scanner over a sphere on a plane), not from
real hardware. 1920 × 1080, dark theme.

| File | What is on screen |
|---|---|
| `01-live-scan.png` | Scanning: the model grows in the 3D view while the scanner (blue outline) moves. Camera and depth pictures top right, distance gauge, tracking status and frame counts. |
| `02-viewer-measure.png` | The finished mesh in the result viewer with a point-to-point measurement (499.55 mm) and the size, check and download panels. |
| `03-stereo-calibration.png` | Setup wizard, stereo calibration: both camera pictures with the detected board, the next pose to move to, and the coverage map, variety and captured views. |
| `04-process-studio.png` | The processing studio: the stages (track, straighten, fuse, refine) on the left, the mesh, and mesh statistics, tolerance check, downloads and recipes on the right. |
